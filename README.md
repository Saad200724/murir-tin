# মুড়ির টিন 3D (Murir Tin — ওস্তাদ বাম প্লাস্টিক!)

বাংলাদেশের রাস্তার লোকাল বাসের রোমাঞ্চ, চাপানি আর মিম কালচার নিয়ে তৈরি সম্পূর্ণ ফ্রি-টু-পাবলিশ ৩ডি ওয়েব ও মোবাইল গেম (`D:\Murir Tin`)।

---

## ফোল্ডার পরিচিতি
- **`build/webgl/`** — সরাসরি হোস্ট করার জন্য রেডি প্রোডাকশন 3D WebGL বিল্ড (`index.html`, JS/CSS, এবং ৭টি `.glb` 3D মডেল)।
- **`release/MurirTin-WebGL-Publish.zip`** — এক ক্লিকে **itch.io / Cloudflare Pages / Netlify / Vercel / CrazyGames**-এ আপলোডযোগ্য ZIP।
- **`web-3d/`** — সম্পূর্ণ সোর্স কোড (Three.js + TypeScript + Vite + Vitest + Capacitor + Node `.glb` জেনারেটর)।

---

## গেমের ফিচারসমূহ
- **৭টি কাস্টম Binary glTF 2.0 (`.glb`) 3D মডেল:** মুড়ির টিন লোকাল বাস, প্রাইভেট কার ("প্লাস্টিক"), উল্টা পথের "দেশি টেসলা" অটো, সবুজ CNG, কার্গো ট্রাক, ট্রাফিক সার্জেন্ট, ও বাদুড়ঝোলা যাত্রী।
- **আসল ঢাকার হাইওয়ে:** মেট্রোরেল ভায়াডাক্ট ও পিলার, রুট প্রোগ্রেশন (`মিরপুর ১০ ➔ কাজীপাড়া ➔ আগারগাঁও ➔ বিজয় সরণি ➔ ফার্মগেট ➔ শাহবাগ ➔ মতিঝিল ➔ গুলিস্তান`), এবং **3D স্পনসর বিলবোর্ড**।
- **চাপানি ও ওভারলোড ফিজিক্স:**
  - **বাম প্লাস্টিক / ডান চাপানি:** প্রাইভেট কারের গা ঘেঁষে বের হলেই **স্পার্ক + কম্বো ৳ বোনাস + নাইট্রো চার্জ**!
  - **রানিংয়ে বাদুড়ঝোলা যাত্রী:** বাস স্টপ থেকে যাত্রী তুললে ৩ডি বাসের ছাদে ও পাদানিতে যাত্রী চড়ে আর টার্নিংয়ে বাস কাত হয়ে দুলে ওঠে!
  - **হাইড্রোলিক হর্ন (`📢 হর্ন`):** হর্ন বাজালে সামনের গাড়ি ও CNG সাইড দেয়!
  - **নাইট্রো (`🔥 নাইট্রো`):** খোঁড়াখুঁড়ির ব্যারিকেড ভেঙে আর সার্জেন্টের সামনে দিয়ে উড়াল দিয়ে পালানো!
- **ধোলাইখাল গ্যারেজ ও স্কিনস:** ইঞ্জিন টিউনিং, বাম্পার হেলথ, নাইট্রো সিলিন্ডার ও ৪টি বাস স্কিন (*মুড়ির টিন ক্লাসিক, বলাকা তুফান মেইল, ডিস্কো চিড়িয়াখানা, ধোলাইখাল সম্রাট*)।
- **ভাইরাল মিম স্কোরকার্ড (PNG ডাউনলোড + কপি চ্যালেঞ্জ):** ক্র্যাশ করলেই ফেসবুক/মেসেঞ্জারে শেয়ার করার জন্য মজার বাংলা রিপোর্ট কার্ড!

## লোকালি চালানো ও টেস্ট করা
```powershell
cd "D:\Murir Tin\web-3d"
$env:NPM_CONFIG_CACHE="D:\npm-cache"
npm test          # Vitest ইউনিট টেস্ট ও .glb ভ্যালিডেশন
npm run build     # 3D মডেল জেনারেট + TypeScript চেক + WebGL বিল্ড
npm run package   # release/MurirTin-WebGL-Publish.zip তৈরি
npm run preview   # http://127.0.0.1:4174/ এ গেম চালু করা
```
